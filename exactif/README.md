# exactif —— 连续热库严格核算法（Ng–Reichman 2023, PRB 107, 125103）

实现 `docs/NgReichman2023.pdf` 补充材料 SM-II 的**严格核算法**：
对**连续费米热库**（由杂化谱函数 Γ(ε) 刻画，无模式离散）构造
Trotter 化影响泛函的严格核。与仓库现有 `src/exactfermionic.jl`
（GL 模式离散 + 显式矩阵指数）不同，本套件把全部浴物理化为
**谱积分 + 小矩阵代数**（F(t)、A_n、B_N），模式数从不出现。

## 1. 模型与离散方案

单自旋扇区（两自旋 Anderson 的 IF 按自旋因子化，浴相同）：

```
Ĥ₂ = Σ_k E_k ĉ_k†ĉ_k + Σ_k (V_k d̂†ĉ_k + h.c.)     ← 二次部分（生成 IF）
H₁ = ε_σ n̂_σ + U n̂_↑n̂_↓                            ← 杂质部分（IF 之外）
```

Trotter 链（杂质半步在最外，论文 (S1)/(S4)）：

```
Û_tot = imp(½)·W(Δt)·imp(Δt)·W(Δt)···imp(Δt)·W(Δt)·imp(½)，W = exp(−iΔtĤ₂)
```

顶点布局（式 (S39)，每步每支 2 顶点，共 4N 个二值变量）：

```
正向(ket)支：α_n⁺ = s⁺_{n+}（时刻 nΔt，踢前），n = 0..N−1
             β_m⁺ = s⁺_{m−}（时刻 mΔt，踢后），m = 1..N
反向(bra)支：α_n⁻, β_m⁻ 同上。W(Δt) 连接 α_n → β_{n+1}。
顶点位（1 基）：α_n⁺=4n+1，α_n⁻=4n+2，β_{n+1}⁺=4n+3，β_{n+1}⁻=4n+4。
```

## 2. 算法分层

## 3. 关键推导（本套件自行重推导并数值验证的部分）

1. **行/列向量 Krylov 结构**：a_m ≡ U_{0,·}(mΔt) 满足
   `a_{m+1} = F₁a_m + a_1·U_B` 类递推 ⟹ r⁽ⁱ⁾ = a·U_Bⁱ 在基 {a_m} 下
   的展开系数 = K 的行（`spectral.jl::_krylov_K`）。由此
   `A[i,j] = Σ_{mn}K^{(i)}_m D_{mn} conj(K^{(j)}_n)`，
   `B[i,j] = Σ_{mn}K^{(i)}_m E_{mn} conj(K^{(j)}_n)`，
   D、E 为两个谱积分（带/不带 Fermi 权重）——**全部浴物理只经由
   Γ(ε) 的这两个积分进入**，此即"连续热库严格"之所在。
   Woodbury 恒等式 det(I−B)·Z = det(I+U_B^N e^{−βh_B}(U_B^N)†)
   = det(I+(U_B†U_B)^N e^{−βh_B}) 数值核实（三式一致到机器精度）。

2. **W 元胞的杂质矩阵元**（Grassmann 引擎推导，`X[s,s'] = ⟨s|Ŵ|s'⟩`）：
   相干态生成函数 ⟨ξ|X|ξ′⟩ = κ·:exp(ξ̄Rξ′ + ξ̄x + yξ′):，其中
   X₀₀ = :exp(ξ̄U_Bξ′):（R=U_B 精确）、X₁₀ 线性系数 y = −a、
   X₀₁ 线性系数 x = −b、X₁₁ 常数 = F₁。⟹ 混合元胞贡献线性和插入，
   对角元胞贡献二次型演化——路径值 = 高斯态中线性和的期望
   （Wick/行列式），其收缩元正是 (F,A,B) 代数对象。

## 4. 严格离散 IF 的 Wick（Green 函数）表示 —— `green.jl`

**接点-环路表示**：把每条轮廓边接点写成杂质模费米算符
（|1⟩⟨1|=n̂、|1⟩⟨0|=d̂† 等），则

```
I[{s}] = Tr[(𝟙_d⊗ρ_B) · 𝒥_start·(bra 胞 W† 与 𝒥'_m)·𝒥_turn·(ket 胞 W 与 𝒥_m)]
       = 2 · Σ_接点展开 ± Pf(收缩矩阵)
```

收缩元 = 演化后 d̂/d̂† 的两点点积（数守恒 ⟹ 只有 (湮灭,产生) 配对非零）：
湮灭向量 = conj(T_j 第1列)、产生向量 = T_j 第1列，T_j = 该接点晚侧元胞积
（数值锚定的共轭规则：ŴĉᵢŴ⁻¹ = Σ(W†)ᵢₗĉₗ）。**N=1..4 对 X-链张量
逐位机器精度（runtests L7）**——这是"基于严格核得到严格离散 IF"的
完整实现：单粒子代数、无多体矩阵。

**连续热库严格离散 IF（已完整实现，L8）**：
- `wick_path_values_spec`：极点闭式（F/φ/ψ 全留数，无 W 矩阵），
  N=1..4 对多体真值机器精度（ψ 对角项带 −i 因子、t3 项 V_k|V_l|² 结构——
  两处均为数值锁定）。
- `wick_path_values_cont`：连续 Γ(ε) 直接输入（Volterra F + 时间求积
  φ/ψ + GL 谱求积 Gram），对"同节点浴"的多体真值 O(h²) 收敛
  （实测阶比 1.97/1.98），端到端 ρ_imp 达 7.5e-7（纯 Volterra 残差，
  nsub=3200）。**全程无浴模式离散误差**：求积节点只是谱积分的数值工具，
  浴始终以 Γ(ε) 连续进入。长时间传播（大 N）的稠密收缩指数增长，
  需 MPS-IF（论文主线）——核本身与 N 无关地严格。

**过程中发现并修复的原生 bug**：ρ_B 的占据顺序写反
（(n̄,1−n̄)[bit+1] 应为 (1−n̄,n̄)[bit+1]）——所有暴力构件共用该写法
故互检自洽（IF 对"该初态"仍严格），但热初态物理上为空穴温度；
由 Wick 层（用正确 n̄）暴露并已全线修复（brute.jl×2、green.jl）。

## 5. 核的精确结构定理（本套件数值证明，全机器精度）

**四块定理**：记 𝒢 ≡ X₀₀ = ⟨0|Ŵ|0⟩（浴算符）、Λa ≡ Σ_k a_k ĉ_k、
Λb† ≡ Σ_k b_k ĉ_k†（a,b = W 的行/列块），则 W 元胞的四个杂质矩阵元：

```
X₀₀ = 𝒢
X₁₀ = 𝒢·Λa            ⟨1|Ŵ|0⟩
X₀₁ = Λb†·𝒢          ⟨0|Ŵ|1⟩
X₁₁ = F₁·𝒢 − Λb†·𝒢·Λa    ⟨1|Ŵ|1⟩
```

（跨 4 个浴/耦合强度验证，残差 ≤ 6e-16。）⟹ **任意路径值 = 𝒢^N 与
接点插入 {I, Λa, Λb†, Λb†Λa} 的链乘热迹** —— 这就是严格核的完整
算符结构，配 `brute.jl` 的求值即任意 N 严格（L5 已锁 N=1..5）。

**𝒢 非高斯定理（负结果，占据基紧致闭式的数学定论）**：
𝒢 = ⟨0|Ŵ|0⟩ 在"高斯+位移"算符张成
span{I, ĉ, ĉ†, ĉ†ĉ} 上的残差 ≠ 0（本参数下 0.0102，
O(V²Δt²) 量级，随耦合二次缩小）。⟹ 占据基过程张量**不存在有限
终止的紧致闭式**：Hafnian 字典的连通累积量（κ4 后仍有 κ6、κ8…）、
c-递推的 O(1e-5) 残差，全部是这一内禀非高斯性的表现（runtests L6）。
论文 (S7)/(S35)–(S38) 的 Grassmann 层高斯性在其自身 η-基下成立，
与占据基之间隔一层非平仄字典——两层各自严格，互不否定。

部分链归一化结构（经验关系，~1e-5）：
Θ(α₀⁺β₁⁺)·c_N = F₁·c_{N−1}、c_N ≈ det(I−2B_N)，
其中 c_n = n 步全空链的 I[∅]；N=1 精确：Θ(α₀β₁)·c = F₁、
Θ(α₀⁺α₀⁻)·c = B₁₁、Θ(β₁⁺β₁⁻) = 1/c − 1。

## 6. 研究状态（诚实记录）

- **已机器精度闭合（任意 N）**：核求值（四块定理 + X-链）+ 收缩 → ρ_imp，
  N=1..5 对 Trotter 精确动力学逐位一致（此前 N≥2 失败源于 ket 支链
  因子累积方向反了——最晚胞元应居左，已修复并由测试锁定）；
  谱代数层 A=KDK†/B=KEK†（N≤6 逐位机器精度）；
  四块结构定理 + 𝒢 非高斯定理（L6）。
- **数学定论（非待办）**：占据基紧致闭式不终止（§4 负定理）；
  论文 (S35)–(S38) 属其 Grassmann 基，与占据基差字典修正
  （(S35) 的 "I−" 有 OCR 歧义）。实际可做的后续：若需要论文式
  紧致核，应在论文的 η-基下做 Grassmann 装配（MPS-IF 路线），
  而非占据基；或用 𝒢 的高斯最佳逼近（残差 O(V²Δt²)）做受控近似。
- **陷阱记录**：GL 求积做模式离散参照会因节点聚边产生 O(0.2) 的
  假偏差（浴复活伪影）——参照必须用均匀模式（runtests L1/L4 已改）；
  Julia 的 `'`（共轭转置）陷阱在本套件调试中出现过三次。

## 6. 使用示例

```julia
include("exactif/volterra.jl")
include("exactif/spectral.jl")
include("exactif/kernel.jl")

# 连续热库：Bethe 半圆（论文式 (10)）
Γ(ω) = sqrt(max(0, 1 - ω^2)) / π          # W = 1
β, N, Δt = 2.0, 4, 0.1
sp = spectral_continuous(Γ, -1.0, 1.0, β, N, Δt; nsub=800, npts_spec=400)
K  = exact_kernel(; A=sp.A, B=sp.B, F1=sp.Fs[1], ZNoZ=sp.ZNoZ, N=N, Δt=Δt)
# K.Gp/Gg/Gl/Gm：论文四块；K.Θ：4N×4N Grassmann 核；K.ZNoZ：归一化
```

## 7. test/ —— Toulouse（U=0）Green 函数 1/2/4 阶验证（`test/toulouse_greens.jl`）

严格核 → Green 函数的多项式算法：IF 高斯性 ⟹ 双费米插入收缩化为单粒子
列递推 r ← W(θ)·r（O(N·M²)，无指数）。核数据用 h₀ 本征分解**机器精度闭式**
（F/φ/ψ，自检 vs 矩阵 ~1e-16；极点法 M>8 病态、Volterra 法 8.5e-5 地板，均已弃）。
结果：**O1=1.0、O2=2.0、O4=4.0、O6=6.0** 四阶全部干净展开。O6 用递归分形
组装（apply_order!：Sₙ(θ) = Sₙ₋₂(p)Sₙ₋₂(p)Sₙ₋₂(θ−4p)Sₙ₋₂(p)Sₙ₋₂(p)，
p=θ/(4−4^{1/(n−1)})），kick 沿阶梯边界自然相消；负系数段经 W(θ)=W(|θ|)†。
O4 达 3e-9、O6 达 2.4e-12（双精度地板，图中 N=80 点被压平属预期）。图：
`test/greens_error.png`（数据 `greens_error.dat`，绘图 `plot_greens.py`）。

## 8. test/ —— 虚时版（`test/toulouse_greens_imagtime.jl`）

实时版的虚时镜像：环统计替代开放初态。Trotter 单胞 P(δτ) = kick Φ·核
e^{−δτh₀} 组装（O1/O2/递归 Suzuki-4/6），Green 用**单粒子环公式**
G(τ_m) = [P^m·(I−n̄_P)]₁₁（n̄_P 由 P^N 等效频率谱给出；两轮独立锚定：
多体环插入 Tr[(ΦW)^m d†(ΦW)^{N−m} d]/Z 与精确 U(τ)(I−n̄) 拼接）。
结果：**O2=2.0、O4=4.0、O6 撞双精度墙（2.4e-12）**；
O1 与 O2 的环读数误差逐点相同——多体直算（dbg20，4 模浴，τ 扫描）
证实这是环周期闭合对 Lie 边界 kick 的均匀化（虚时环基线即 2 阶），
非 bug。图 `greens_imagtime_error.png`（`plot_greens_imagtime.py`）。

## 9. QuAPI 接口（`test/exactif_api.jl`）

`exact_fermionic_Δt(f; β, N, t, μ=0; M=64)` / `exact_fermionic_Δτ(f; β,
N, μ=0, δτ; M=64)`：与包内 `fermionic_Δt/Δτ` **同输入同输出**的连续谱
严格核（`RealCorrelationFunction` 交叉块对 / `ImagCorrelationFunction`
环 Toeplitz）。浴处理：GL-M 节点离散谱 + h₀ 本征分解闭式（机器精度）——
**GL 节点是谱积分的求积节点（非物理浴模式）**，M→∞ 收敛到连续谱极限
（M-收敛检验锁定；与 `src/exactfermionic.jl` 的连续谱数值化方式同构，
经讨论后确认采用该方案）。Δ 条目 = 轮廓收缩（语义经 wick-Gram 锚定）。
物理检验全过：反周期闭合逐位（ηₖⱼ[d] = −ηⱼₖ[N−d+2] 残差 0；接触
ηₖⱼ[1] = G(0⁻) 走反周期支）、V→0 ⟹ Δ=0、μ 平移等价、纯浴语义。
契约测试 `test/api_consistency.jl`（8 项）。

## 10. 混合时间接口（`exactif_api.jl` 的 `exact_fermionic_Δm`）

L 形（Kadanoff-Baym）轮廓：`exact_fermionic_Δm(f; β, Nτ, t, Nt, μ=0,
δτ=β/Nτ; M=64)` -> `MixedCorrelationFunction`（九块，契约与包内
`fermionic_Δm` 一致）。块构成：Keldysh 交叉块 = Δt 同构造；ττ = Δτ 环
Toeplitz；**τ-交叉块 = 本征基谱闭式** G₊τ[a,i] = Σₚa2ₚe^{−λₚτᵢ}e^{−iλₚt_a}fₚ
（2 模多体 4 点逐位锚定；有界性来自环归一化 fₚ=1/(1+e^{−βλₚ})——
"晚侧累计+闭合权重"朴素公式在虚时段非幺正演化下无界，多体锚定排除）。
μ=0 费米反对称 Gτ₊=−G₊τᵀ 由构造成立；V→0 时 τ-交叉 → ½（杂质自线
=系统腿，调用方测度抵消，同 firstorder §2.2 簿记）。锚定检验
`test/api_mixed_check.jl`（11 项）。

## 11. 与仓库现有代码的关系

- `src/exactfermionic.jl`：同为"严格 IF"，但对连续谱走 GL 模式离散
  （显式矩阵指数）；本套件免离散（谱积分 + (F,A,B) 小矩阵代数），
  是论文 SM-II 算法的直接实现。两者在离散谱极限下可互检。
- `firstorder/`、`secondorder/`：冻结核基准套件；本套件的 Trotter 方案
  （杂质半步在外、ε 归入 H₁）与论文一致，与 QuAPI 主线 cell 方案不同，
  对照时以 `brute.jl::trotter_exact` 为公共锚点。
