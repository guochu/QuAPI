# performance/secondorder/ —— 冻结影响泛函之上的直接二阶（Weyl-K）方案总结

本目录的基准实现并验证了一件事：**只用一阶离散的影响泛函（冻结核）数据，在 Keldysh
侧（"K 侧"）做正确的装配，就能对实/虚/混合三种时间轮廓、玻色/费米 normal/BCS 三种
浴全部达到直接的二阶精度**——不需要 Trotter 重排、不需要 Richardson 外推、不需要任
何精确解输入。本文档总结各扇区的具体装配、杂质部分的处理，以及背后的数学原理：
为什么一阶的 IF 能给出二阶的 Trotter 演化精度。

## 0. 结果总览（全部对精确参照实测，误差阶数）

| 轮廓 | 玻色 normal | 费米 normal | BCS（实/复 Δ） |
|---|---|---|---|
| 实时 | 2.00 | 2.00 | 2.00 / 2.00 |
| 虚时 | 2.00 | 2.00 | 2.00 / 2.00（含反常分量） |

## 1. 数学原理：为什么一阶 IF + K 侧装配 = 二阶

本节以**单模浴**为贯穿例子做完整推导与数值验证（模型参数 ϵ_d=0.5、ε=1、V=0.3、
β=4、T=4；全部数字为实测，可由 `fermionic_Δt` 单模数据复现）。

### 1.1 从哈密顿量到连续 Dyson 方程

单模 Toulouse：H = ϵ_d d†d + ε c†c + V(d†c + c†d)。推迟振幅
A(t) = −i⟨{d(t),d†(0)}⟩ 满足单粒子图像的 2×2 精确解
A(t) = [e^{−iHt}]₁₁ = cos²θ·e^{−iλ₊t} + sin²θ·e^{−iλ₋t}（H 的本征分解）。
消去浴模振幅 B(t) = [e^{−iHt}]₂₁（B(0)=0）得**连续记忆方程**：

    i∂_t A(t) = ϵ_d A(t) − iV²∫₀ᵗ e^{−iε(t−s)} A(s) ds,   A(0) = 1.

有限温度下核带热权重：大于/小于分支分别 (1−n_F)、n_F 加权，但**推迟组合中
n_F + (1−n_F) = 1 精确相消**——这正是 §4 速查表中 X−P / −(Δ⁺⁺+Δ⁺₋) 的来源，
也说明 K^R 与杂质态无关。虚时与混合扇区的方程同构（τ 支 e^{−ετ} 实衰减 +
KMS 反/周期边条件；混合轮廓加 ζ 交连源），见 §2/§6。

### 1.2 冻结 IF 条目的解剖：精确的双重 cell 积分

`fermionic_Δt` 给出的条目不是核的节点采样，而是**cell 对上的精确双重积分**
（quadgk 机器精度）。单模数值验证（|K(d)| = V²h²·(1+O(h²))，与 cell 形状因子
|Q(σ)|² = |(1−e^{−iεσ})/(iεσ)|² 的接近度 > 0.99，相位由 face-value 配对约定固定）：

    N=16:  |K| = 5.60e-3 = V²h²·0.9956     N=64:  |K| = 3.51e-4 = V²h²·0.9984

**关键量纲事实：条目是 O(h²)**（Dyson 方程本身是双重时间积分的 Volterra 结构）。
若把条目误读为 h·K(节点值)，误差是 O(1) 相对量（实测 |K(d) − h·K^R(节点)| ≈
4|K(d)|）——这就是"节点语义"失败的定量面貌。IF 的"一阶性"从来不是数据误差，
而是把 cell 积分条目**当节点值**去做 Trotter 组合的解释误差（顶点自能 V³/V⁴、
cell 内路径细节在那种组合里根本不被表示）。

### 1.3 K 侧装配：对连续 Dyson 方程的单步法

K 侧方案不组排 cell，而把 1.1 的连续方程当 ODE 初值问题逐 cell 推进：

    A[m+1] = ( u·A[m] − f·Σ_{k=1}^{m−1} K(m+1,k+1)·φ_k − f·d₀·A[m]/2 ) / (1 + f·d₀/2)

    φ_k = (A[k]+A[k+1])/2（梯形源）  u = e^{−iϵ_d h}（整步自由相位）
    f = e^{−iϵ_d h/2}（半步相位）    d₀ = K(1,1)（等时接触，隐式）

由于条目 O(h²)，核求和 Σ_k K·φ **每步是 O(h)**（实测：m=N 处 |s| = 5.7e-2/
1.4e-2/3.6e-3 @ N=16/64/256，严格 ∝h），经 N=T/h 步累积成 O(1) 的卷积效应——
这是一个 Runge–Kutta 型单步法，不是对固定积分的求积。

### 1.4 逐项误差账目：局部 O(h³) ⟹ 全局 O(h²)

把精确解 A(t) 代入格式，每步残差有三个来源，逐一核对到 O(h³)：

1. **源 cell 梯形**：cell k 上 ∫(A(s)−φ_k)ds = h³A''/12 + O(h⁵)（梯形积分误差，
   一阶矩相消），再乘吸收 cell 的 h ⟹ 每 cell 对 O(h⁴)，对 k 求和 O(h³)/步。
   若改用左矩形（φ_k→A[k]）：∫(A−A_k)ds = O(h²) ⟹ O(h²)/步 ⟹ 全局一阶。
2. **吸收 cell 中点相位 f**：∫_{cell m}e^{−iϵ_d(t_{m+1}−s)}g(s)ds = f·h·g(中点)
   + O(h³)（中点公式）。若 f→1（左端点）：O(h²)/步 ⟹ 全局一阶。
3. **同 cell 接触 d₀**：k=m 项是格式的一部分，φ_m = (A_m+A_{m+1})/2 隐式
   （显式 −f·d₀A_m/2 + 分母 (1+fd₀/2) 正是该隐式解的移项）。若整体删去：
   每步丢 O(h²) ⟹ 全局一阶。
   浴相位在 cell 对上的积分**无误差**（条目即精确积分，1.2）。

局部残差 O(h³) + Volterra 离散 Grönwall ⟹ 全局 O(h²)。三要素缺一掉阶是
可实测的（下表）。

### 1.5 单模算例：数值验证

完整方案 vs 精确解（1.1 闭式）：

    N= 16   err=1.602e-03
    N= 32   err=4.018e-04   order=2.00
    N= 64   err=1.005e-04   order=2.00
    N=128   err=2.514e-05   order=2.00
    N=256   err=6.285e-06   order=2.00

消融（逐要素删除后的阶数序列 N=32..256）：

    去梯形源（左矩形）  0.92 0.96 0.98 0.99   → 一阶
    去半步相位（f=1）   0.98 0.99 1.00 1.00   → 一阶
    去接触（d₀=0）      1.05 1.03 1.01 1.01   → 一阶

与 1.4 的账目逐条对应。虚时的第 4 要素（双侧跳变）同理：KMS 边条件
G(0⁺) = ±1 − G(β⁻) 必须同时代入自由项与 φ₁ 左半，只代一半 = 源 cell 用了
错误的端点值，O(h²)/步 ⟹ 一阶。

### 1.6 与严格 Trotter 链的关系

同一 IF 数据的严格 Strang 链在实/虚时也是二阶（Lie≡Strang 节点简并）——说明
这批数据内在支持二阶；Weyl-K 与链之差为 O(h²)（玻色侧实测差距比值恒 4.0，
U1GTEMPO2 自家 order=2 代码同构）。两条路线的分野在混合轮廓：Keldysh 轮廓上
严格链只有一阶（无简并），Weyl-K 仍直接二阶——"IF 不变、阶数由 K 侧修正承担"
的核心证据。Weyl-K 误差为 h 的偶函数 ⟹ Richardson (4S(h/2)−S(h))/3 → 四阶
（实测 4.00）。虚时环另有两个结构性要点：τ 支相位是实衰减 e^{−ϵδτ}（无 i）；
ε<0 模的 Boltzmann 权重在混合 γ 收缩中有峰宽 1/|ε| ≪ h 的欠采样病理，必须
消峰分拆（§6）。

## 2. 虚时扇区：环方程装配

未知量为 N 个节点值 G[m] ≈ G(τ_m)，τ_m = m·δτ。装配为线性系统 M\,b，行结构
（费米 greater 约定 G = −⟨d(τ)d†(0)⟩）：

    G[m] − uτ·G[m−1] − fτ·Σ_k w(m,k)·φ_k = 0，
    w(m,k) = ηⱼₖ/ηₖⱼ/接触(ηⱼₖ[1]+ηₖⱼ[1])（核环用法，τ 支实衰减相位
    uτ = e^{−ϵ_d δτ}、fτ = e^{−ϵ_d δτ/2}——虚时无 i！用实时间相位会 O(1) 坏）。

**第 4 要素（双侧跳变）**：KMS 边条件代入第 1 行的自由项**和** φ₁ 的左半：
费米 G(0⁺) = −1 − G(β⁻)（b[1] −= uτ、M[1,N] += uτ、φ₁ 左半 = (−1−G_N+G₁)/2）；
玻色 G(0⁺) = G(β⁻) + 1。只代自由项不代 φ₁ → 一阶。

- 玻色：环直接消费 bosonic_Δτ 的 .data 向量；若从 Δm 的 ξ 块取数，用
  branch(τ,τ) 的**场**（≡ Δτ 条目；原始 ξ 向量 = −Δτ 条目，直接用会差整体负号）。
- 费米：ηⱼₖ/ηₖⱼ 原样（+）。
- **BCS**：未知量升为 Nambu 2×2 四分量 𝒢[p,q][m]（p=τ 端行、q=0 端列），
  第一行方程牵连第二行，必须四分量全闭合。行相位：粒子行 (e^{−ϵδτ}, e^{−ϵδτ/2})、
  空穴行 (e^{+ϵδτ}, e^{+ϵδτ/2})（𝒢₂₂ ∝ e^{+ϵτ} 增长）。跳变常数只有对角分量
  （𝒢₁₁、𝒢₂₂ 行 G₀ = −1−G_N；反常分量 G₀ = −G_N，不同模无 δ 源）。核 k=1 的
  跳变代入用未知列指标 cp(s,j)。反常分量的提取符号差一个整体负号（列腿序约定），
  输出乘 (p==q ? +1 : −1)。

严格参照：费米 = 精确热环 −[(T^m)(I+T^N)⁻¹]₁₁（机器精度）；BCS = Strang cell
环 M(τ_m) = st^m·M₀。自由极限 V=0 是第一调试工具（逐点机器精度）。

## 3. 实时扇区：推迟递推装配

单列递推（§1.3 公式），核为推迟组合（速查表 §4）。杂质部分（见 §5）以自由相位
u 与半步相位 f 精确处理。

- 玻色：K^R = −(Δ⁺⁺+Δ⁺₋)（(1+n)−n 相消）；杂质为一般 hS 时 u = e^{−ih_S h}、
  f = e^{−ih_S h/2}（矩阵相位），A 为矩阵列递推。
- 费米：K^R = X−P（n+(1−n) 相消；单模验尸 Δ⁺⁺ = −(1−n)R、Δ⁺₋ = +nR——Pauli
  反映射）。
- **BCS**：核升为 2×2 Nambu 矩阵，行相位粒子 (e^{−iϵh}, e^{−iϵh/2})、空穴
  (e^{+iϵh}, e^{+iϵh/2})（互为共轭）。正常槽位（cn/nc 块）X−P；反常槽位
  （cc/nn 块）**P−X**（与正常相反：cc 块的对称化把 e^{±iEt} 两支都装进 (+,+) 与
  (+,−) 元，P−X 给出正确的 sin 结构推迟核 −_uv φ₊ + _uv φ₋）。接触为 2×2 等时
  矩阵 D₀，按列解隐式系统 (I + Diag(f_p)·D₀/2)·A[m+1] = RHS。
  **复 Δ 正确性依赖 2026-10-29 核心修复**：fermionic_Δt 反向扇区走负滞后路线
  （fⱼₖ(−i)·g₂，不共轭谱权重）——反常关联 F(s) = (1−n)·_uv·e^{−iEs} 在正负滞后
  携带同一未共轭相干权重，任何 conj 派生都会在复 Δ 下给 conj(_uv)。

严格参照：BdG 单粒子问题的 Strang 分裂链 st = e^{h_A/2}e^{h_B}e^{h_A/2}（实/虚时
Lie≡Strang 节点值简并）。

## 5. 杂质部分的处理

K 侧方案中杂质**不做离散化**——其自由演化被解析地积出，以相位因子进入装配：

| 扇区 | 杂质自由相位 u | 半步相位 f | 说明 |
|---|---|---|---|
| 实时费米 | e^{−iϵ_d h} | e^{−iϵ_d h/2} | Toulouse 标度模型 |
| 实时玻色 | e^{−ih_S h}（矩阵） | e^{−ih_S h/2} | 一般自旋-玻色 H_S |
| 虚时 | e^{−ϵ_d δτ}（实衰减，无 i） | e^{−ϵ_d δτ/2} | |
| BCS 全部 | diag(e^{−iϵ_d h}, e^{+iϵ_d h}) | 对角半步 | Nambu h_𝓝 = diag(ϵ_d,−ϵ_d)，空穴行相位共轭 |

跳变常数（虚时环）也属杂质—浴交连的等时结构：费米 {d,d†} 反对易 ⟹ G₀ = −1−G_N；
玻色 {b,b†} 对易 ⟹ G₀ = G_N + 1；BCS 反常分量无 δ 源。混合轮廓的初值数据
（n_d、M₀ 元素）从环端点反解：费米 n_d = −G(β⁻)；BCS ⟨d↑d↑†⟩ = 1+𝒢₁₁[N]、
反常 ⟨d̄↓†d↑†⟩ = 𝒢₂₁[N]。

## 6. 混合时间扇区（L 形 Kadanoff 轮廓，全平衡 G>）

目标：τ 环热化的全平衡 G>(t)（含 γ 非对角初关联；即 U1GTEMPO2 的 mixed 目标，
其对全平衡 ED 实测 order=1→0.98 / order=2→2.00）。三段式：

**① τ 环**：与 §2 相同的环方程，数据取自单次 Δm 调用的 ξ 块（branch(τ,τ) 场
≡ bcs_Δτ/fermionic_Δτ 环数据，μ=0 逐元相等）。

**② γ 初关联收缩**（从环解提取 ⟨c_k d†⟩ 型初关联）：
- 费米 normal：γ_k = V_k·[G₀·W_tot + Σ_j w_j(G_j−G₀)]/(1+e^{−ε_kβ})，
  W_tot = (1−e^{−εβ})/ε。**消峰分拆必需**：ε<0 模的权重 e^{|ε|(β−s)} 峰在 s=0、
  宽 1/|ε| ≪ h，直接梯形永久欠采样（一阶病态）；分拆使余项在 s=0 消失。分母
  KMS "1 PLUS" e^{−εβ}。该式是下方 BCS 版的 Δ=0 标量极限。
- BCS：每模 2×2 ODE 族收缩。g = (⟨c_k↑d↑†⟩, ⟨c_k↓†d↑†⟩) 满足
  ∂g = [[−ε,−Δ],[−Δ*,ε]]·g + V·(𝒢₁₁, −𝒢₂₁)（源符号 (+,−)，BdG 行方程 +
  [AB,C] 恒等式双推、真值函数差分 1e-12 验证）；**严格反周期** g(β⁻)=−g(0⁺)
  （不同模 {c,d†}=0 无跳变）；τ=0⁺ 源值用环跳变代入；消峰分拆
  X₀ = −(I+e^{Mβ})⁻¹[M⁻¹(e^{Mβ}−I)s₀ + CN-Σ]。双族对 M₀ 精确目标 2.00 收敛。

**③ 实时支 A + C 通道**：A 走 §3 递推（Δm 约定核）；C 走**同一递推（零初值）**
加局部 Duhamel 源：
- 费米：S_m = Σ_k (−iV_k)·I_k(m)·(−γ_k)，I_k(m) = e^{−iε_k t_{m−1}}·e^{−iϵ_d h}·
  (e^{iω_k h}−1)/(iω_k)，ω_k = ϵ_d−ε_k（相位基准 e^{−iε_k t_{m−1}}e^{−iϵ_d h}
  是关键，错基准 → 一阶）。注意自洽配对：局部源配 η 块 Δ 递推；全历史源配 𝒦
  单重卷积递推；混配不自洽。
- 玻色：ζ⁺ᵗ 交连块 × 环梯形值**显式收缩**（玻色 ζ 非 rank-1）：rhs_m =
  f·Σ_j ζ[m,j]·φ^τ_j，需要两个交叉要素：块行取 [m,·]（起始 cell 约定）与吸收
  半步相位 ×f。
- BCS：源 = ζ 交连的因式分解形式（Nambu Duhamel）：Src_k(m) = −i·[expm(h·
  [[−iD(ϵ_d), 𝒱_k·e^{−i𝓗_bk t_{m−1}}],[0, −i𝓗_bk]])]₁₂·γ_k，𝒱_k = diag(V,−V)
  （空穴耦合 −V，BdG −hᵀ 块）、𝓗_bk = [[ε_k,Δ],[Δ*,−ε_k]]；4×4 block-exp 给出
  cell 内双相位飞行积分精确闭式（正常侧 I_k(m) 的推广）。

**组装**：费米 G>/(−i) = (1−n_d)A + C；BCS G₁> = ⟨d↑d↑†⟩·𝒜₁₁ + ⟨d̄↓†d↑†⟩·𝒜₁₂ + C₁。

## 7. 参照解与验证方法

- 玻色/费米 normal：../common/common.jl（原 benchmark/bosons/common.jl）的精确谱求和 / 严格链；
- BCS：手写 BdG（Nambu 基 (↑粒; ↓穴)），与全 Fock ED、ImpurityModelBase cdm
  演化三方对拍到机器精度（M₀ = I−f(𝓗) 整体式、𝓗 = [[h,B],[B*,−hᵀ]]）；
- 每个基准输出 results/*.csv（Weyl-K 与严格链两列误差）+ plot_results.py 出图；
- 阶数表由逐倍加密阶梯读出（ratio≈4、order≈2.00）；
- 回归协议：改动前后 CSV 逐位对比（本目录历史上多次"看似无害"的改动靠此抓回）；
- 对齐单元测试（test/mixedtime.jl、test/bcs.jl、test/realtime.jl）：Δm 的 τ/实支
  与 Δτ/Δt 逐元对齐、无穷 cache 与 Δt 对齐，机器精度，其中复 Δ 档是共轭存储
  修复的回归卫士。
